ARCHIVE BUILDER FOR WINDOWS

Quick start:
1. Extract the entire ZIP.
2. Run ArchiveBuilder\ArchiveBuilder.exe.

Optional installation:
Run "Install Archive Builder.cmd" to copy the application into your LocalAppData Programs folder and create shortcuts.

CLI:
ArchiveBuilderCLI\ArchiveBuilderCLI.exe --help

Note: unsigned community builds may trigger Microsoft SmartScreen. Verify the SHA-256 checksum published with the GitHub release.
